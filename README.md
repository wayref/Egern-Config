# Egern 懒人配置

开箱即用的 Egern 配置，智能优选自动选择最优节点，支持手动切换。

## 特点

- **智能优选**：11 个服务组各含 12 个选项（6 个地区智能优选 + 6 个智能家宽），自动选择最优节点，无需手动干预
- **31 个策略组**：11 个服务组、6 个地区智能优选（香港/台湾/日本/韩国/美国/新加坡）、6 个智能家宽组、6 个手动组（隐藏备用）、订阅组、兜底组
- **DNS 分流加密**：国内外 DNS 分流，全部走 DoH 加密，防泄露
- **24 条规则**：11 条国外规则（AI、TikTok、Google、Twitter、YouTube、Telegram、Instagram、FaceBook、Threads、GitHub、国外网盘）走对应服务组；9 条国内规则（Apple、腾讯、百度、阿里、字节、网易、三网、China、内网）直连；另有 .cn 后缀直连、GeoIP CN 直连、测速规则、默认兜底

## 使用方法

1. 在 Egern 里添加远程配置，粘贴订阅链接：
   ```
   https://raw.githubusercontent.com/wayref/Egern-Config/main/懒人配置.yaml
   ```

2. 在「我的订阅」策略组里添加你自己的机场订阅链接

3. 完成，智能优选将自动选择最优节点

## 手动切换

- **全手动**：点底部工具栏中的「代理」，把 6 个手动策略组全部取消隐藏，再点进规则更换成需要的手动策略组
- **懒人模式**：无需任何操作，直接使用

## 说明

- 模块只保留 BoxJS、Sub-Store、Script-Hub 三个基础工具
- 需要去广告模块请自行添加
- 本配置为个人使用而建，涵盖香港、台湾、日本、韩国、美国、新加坡六个常用地区。如需使用加拿大、德国、英国等其他地区节点，请在代理界面自行添加规则
