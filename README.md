# Egern 懒人配置

开箱即用的 Egern 配置，智能优选自动选择最优节点，支持手动切换。

## 特点

- **智能优选**：11 个服务组各含 12 个选项，自动选择最优节点，无需手动干预
- **31 个策略组**：11 个服务组、6 个地区智能优选、6 个智能家宽组、6 个手动组（隐藏备用）、订阅组、兜底组
- **DNS 分流加密**：国内外 DNS 分流，全部走 DoH 加密，防泄露
- **24 条规则**：11 条国外规则走对应服务组，9 条国内规则直连，另有 .cn 后缀直连、GeoIP CN 直连、测速规则、默认兜底

## 使用方法

1. 在 Egern 里添加远程配置，粘贴订阅链接：
   ```
   https://raw.githubusercontent.com/wayref/Egern-Config/main/懒人配置.yaml
   ```

2. 进入策略组中的「我的订阅」，填入你自己的机场订阅链接并更新节点

3. 开启代理即可使用，所有服务组会自动通过智能优选匹配当前最优节点

## 手动切换

如果你习惯自己指定固定节点，可点击底部工具栏的「代理」，将隐藏的 6 个地区手动策略组（港/台/日/韩/美/新手动策略）取消隐藏，随后点进规则按需替换为对应的手动策略组即可

## 说明与使用注意事项

1. **内置模块精简**：模块仅保留 BoxJS、Sub-Store、Script-Hub 三个基础工具。如需去广告功能，请自行添加对应的去广告模块

2. **地区覆盖与扩展**：本配置涵盖香港、台湾、日本、韩国、美国、新加坡六个常用地区。如需使用加拿大、德国、英国等其他地区节点，请在「代理」界面自行添加策略组与规则

3. **「智能家宽」为空属正常现象**：各地区智能家宽通过识别节点名中的「家宽 / 住宅 / residential / 家庭 / 家用」关键词自动归类。如果你的机场订阅不包含此类节点，对应分组会显示为空，正常使用智能优选即可

4. **单节点测速互不干扰**：手动测速规则已独立绑定至「我的订阅」。想测试某个单节点的真实带宽时，直接在「我的订阅」中选中该节点测速即可，不会打乱其他 App 的日常分流

5. **AI 与 TikTok 地区限制**：使用 AI 和 TikTok 时，建议在对应策略组中选择美国、日本、新加坡、台湾或韩国的优选/家宽分组，避开香港节点，以免触发风控或无法访问
