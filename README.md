# Egern 懒人配置

开箱即用的 Egern 配置，智能优选自动选择最优节点，支持手动切换。

## 特点

- **智能优选**：11 条国外规则全部指向智能优选组，自动选择最优节点
- **20 个策略组**：6 个地区智能优选（香港/台湾/日本/韩国/美国/新加坡）、6 个智能家宽组、6 个手动组（隐藏备用）、订阅组、兜底组
- **DNS 加密**：全部 DNS 走 DoH，防泄露
- **规则齐全**：AI、TikTok、Google、Twitter、YouTube、Telegram、Instagram、FaceBook、Threads、GitHub、国外网盘走对应地区最优节点；Apple、国内网站直连
- **17 条规则**：11 条国外规则走智能优选，4 条国内规则直连（Apple、ChinaMax、LAN、geoip CN），1 条测速走订阅组，1 条默认走兜底

## 使用方法

1. 在 Egern 里添加远程配置，粘贴订阅链接：
   ```
   https://raw.githubusercontent.com/wayref/Egern-Config/main/懒人配置.yaml
   ```

2. 在「我的订阅」策略组里添加你自己的机场订阅链接

3. 完成，智能优选将自动选择最优节点

## 手动切换

喜欢全手动的用户，在底部工具栏点「代理」，把 6 个手动策略组全部取消隐藏，点进任意规则更换成手动策略，优选家宽也是同理。

家宽节点默认不进入自动组，不会被智能优选选中。如需使用家宽，在工具栏代理里找到对应地区的智能家宽组，手动选择。

懒人模式无需任何操作，点进任意规则更换策略组。

## 说明

- 模块只保留 BoxJS、Sub-Store、Script-Hub 三个基础工具
- 需要去广告模块请自行添加
- 本配置为个人使用而建，涵盖香港、台湾、日本、韩国、美国、新加坡六个常用地区。如需使用加拿大、德国、英国等其他地区节点，请在代理界面自行添加规则

## 更新

配置更新后，在 Egern 里点配置更新即可同步最新版。
